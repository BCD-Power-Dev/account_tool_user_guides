# Country/Security Risk Topics Manager — User Guide

The Country/Security Risk Topics Manager lets you keep short, formatted write-ups ("topics") attached to a Country/Security Risk. Each topic shows the country's current **sanctioned** and **restricted** status automatically, so you always see it in context.

Anyone can browse topics. Adding, editing, and deleting are available to users in the edit-admin group.

## The layout

The screen has two sides:

- **Left — the list.** Every topic, with a search box and a country filter at the top.
- **Right — the details.** The full topic you've selected, including its country status and write-up.

Click any topic on the left to open it on the right.

## Finding a topic

**Search** — type in the search box to match on topic title, its text, or the country name. The list narrows as you type.

**Filter by country** — use the dropdown below the search box to show only topics for one country. The number next to each country is how many topics it has. Choose **All Countries** to clear the filter.

You can use search and the country filter together.

## Reading a topic

When you open a topic, the top of the details pane shows:

- The **title**.
- A **country** tag (with its 2-letter code).
- Status tags, if they apply:
  - 🔴 **SANCTIONED** — the country is currently sanctioned.
  - 🟠 **RESTRICTED** — the country currently has restrictions.
- **SMID** and **LCN** tags, if any were assigned.
- When it was last updated, and by whom.

Below that is the **Detail** write-up, followed by a **Country** card. If the country is restricted and has restriction notes on file, those notes appear in the country card.

> The status tags come straight from the country record. If a country's status changes later, every topic for that country reflects it automatically — you don't need to edit anything.

## Adding a topic

> Requires edit-admin access. If you don't see an **Add** button, you don't have edit rights.

1. Click **+ Add** at the top of the list.
2. Fill in the form:
   - **Topic Title** *(required)* — a short, clear name.
   - **Detail** — the write-up. You can format it (see *Formatting your write-up* below).
   - **Country** — pick from the dropdown. If the country is sanctioned or restricted, a status tag appears right away so you know.
   - **SMID** / **LCN** — click the chips to select any that apply. Use **Select All** or **Clear** to move quickly.
3. Click **Add Topic**.

The form closes, and your new topic appears in the list a moment later.

## Editing a topic

1. Select the topic on the left.
2. Click the **pencil** icon at the top-right of the details pane.
3. Change whatever you need, then click **Save**.

To back out without saving, click **Cancel** or the **✕** in the form's top corner.

## Deleting a topic

1. Select the topic.
2. Click the **trash** icon at the top-right.
3. A confirmation strip appears at the bottom — click **Delete** to confirm, or **Cancel** to keep it.

Deleting is permanent, so confirm you have the right topic first.

## Formatting your write-up

The **Detail** box supports simple formatting through the toolbar above it. Select some text, then click a button — or click a button and type.

| Button | What it does |
|--------|--------------|
| **B** | Bold |
| *I* | Italic |
| H | Heading |
| • List | Bulleted list |
| 1. List | Numbered list |
| 🔗 Link | Insert a link (replace `url` with the address) |
| " Quote | Quoted / callout line |

You don't have to use the buttons — you can type the same formatting by hand if you're comfortable with it. However you enter it, the write-up displays cleanly formatted when you save.

## What the tags mean

| Tag | Meaning |
|-----|---------|
| 🔴 **SANCTIONED** | The linked country is currently sanctioned. |
| 🟠 **RESTRICTED** | The linked country currently has restrictions; check the restriction notes on the country card. |
| **SMID** | This topic has one or more SMIDs assigned. |
| **LCN** | This topic has one or more LCNs assigned. |
| Country name | The country this topic is attached to. |

In the list on the left, sanctioned and restricted topics show a small colored icon so you can spot them at a glance.

## Tips

- **Title is the only required field.** You can save a topic with just a title and fill in the rest later.
- **Status is automatic.** Never worry about keeping sanctioned/restricted flags up to date on a topic — they always follow the country.
- **Nothing saved until you click Save/Add.** Closing or canceling the form discards your changes.
- **Can't edit?** The Add/Edit/Delete controls only appear for edit-admin users. If you need access, contact your app administrator.

## Quick reference

| I want to… | Do this |
|------------|---------|
| Find a topic | Type in **Search**, or pick a country in the filter |
| Read the full write-up | Click the topic in the list |
| See a country's status | Open any topic for that country |
| Create a topic | **+ Add** → fill the form → **Add Topic** |
| Change a topic | Select it → **pencil** icon → **Save** |
| Remove a topic | Select it → **trash** icon → **Delete** |
| Format text | Use the toolbar above the Detail box |
